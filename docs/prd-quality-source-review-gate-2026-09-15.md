# PRD 4 follow-up: mandatory source-grounded automatic review

## Gap and policy

With Quality-first and automatic approval enabled but ai_review.enabled=false, optional text-model review is skipped. OCR presence and model agreement can admit descriptions before their claims are checked against source evidence. The requested policy allows review-assisted automatic approval; it does not require mathematical proof of natural-language meaning and must not claim semantic certification or full accessibility compliance.

## Implementation requirements

Always invoke source review in Quality-first automatic mode. Exact finite pixel facts may pass independently. Other image captions receive one different authorized cloud vision reviewer using the exact source image, under the existing shared ledger and bounded image generation/recovery allowance. Denied permission, unknown usage, unavailable independent reviewer or unusable review stops admission. Reviewer acceptance also requires directly visible source observations supporting every substantive caption term. Reject unsupported quantitative, clinical, identity, ambiguous and chart-association claims, and never override independently known pixel facts. No fabricated reliability scores.

Use existing Office presentation checks and exact PDF figure association. Bind admission to current artifact/image/proposal hashes, a settled reviewer attempt and its durable owner/run/file-scoped receipt, plus immutable generated-proposal snapshots. Never trust cached reviewer flags. Generation defers to the existing approval/writer lane; it does not inline-write review-assisted descriptions. Existing exact saved-value readback, package preservation, actual reassessment and regression checks remain required. Show AI-reviewed approval separately from independently checked pixel meaning and detector-verified saved resolution.

## Acceptance and limits

Offline fixtures cover canonical facts, supported natural-language captions in Office/PDF, changed images/captions, missing receipts, unsettled review spending, unsupported medical/identity/numeric/chart claims, reviewer disagreement/unknown usage, legacy/non-quality behavior and existing saved-byte regressions. No paid evaluations or production deployment here. Release remains governed by existing publishing permissions and the parent task.

Complex charts with numerical/series associations, clinical or identity interpretation, transformed/cropped/shared images, incomplete extraction and semantic changes outside captioning remain explicit unapplied exceptions. This is a conservative approval-confidence policy; lexical observation coverage is not independent semantic proof. Broader chart-data/meaning adapters and bounded model-assisted revision remain follow-up scope. Unsupported cases do not block unrelated eligible fixes or certify full compliance.
