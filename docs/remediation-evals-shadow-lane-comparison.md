# Shadow-mode Claude vs. the current remediation lane — per-criterion recommendation

**Question:** with Claude run only in shadow, which (format, criterion) lanes should change?
**Answer per category:** `enable`, `keep-human-only`, `insufficient-evidence` — or
`no-change-rule-code` where the free deterministic lane already clears it.

**Shadow means:** the Remediation Evals Kit's simulated executor (`evals/world.py`), graded case
by case against a corpus generated from `api/remediation_capability.REMEDIATION` — 100 cases for
the first two runs, then 142 and 143 for the last two. No production path was touched by any of it: no proposer,
route, worker or lane table changed. The only production-facing artefact is the read-only
rollout panel described below.

**Evidence: four paid runs, in two generations of the corpus.** The first two ran on the
100-case corpus; the last two on the fully-sampled corpus, where every category has at least two
cases. Agreement is decided **per category**: a category is judged on the runs that measured
exactly its case set, and a row says how many that was. That is what lets the two fully-sampled
runs be pooled at all — a corpus edit moved two categories between them and the other 58 are
untouched.

### Replication cut the enable set from 11 to 7

Run (a) alone enabled 11 categories. A second run on the same corpus **rejected five of them**:

| category | run (a) said | pooled verdict | why |
|---|---|---|---|
| `pptx:1.1.1` | enable, Opus | **insufficient** | Opus safe 1/2, Sonnet safe 1/2 |
| `xlsx:1.1.1` | enable, Opus | **insufficient** | Opus safe 1/2, Sonnet safe 1/2 |
| `docx:1.4.3` | enable, Opus | **insufficient** | Opus safe 1/2 |
| `html:1.4.3` | enable, Haiku | **insufficient** | Haiku safe 1/2 |
| `xlsx:2.4.4` | enable, Opus | **insufficient** | Opus safe 1/2 |

**Both alt-text (1.1.1) enables failed to replicate, and so did two of the three contrast
(1.4.3) ones — only `pdf:1.4.3` survived.** This is the clearest result the exercise has
produced: one run on a fully-sampled corpus is not sufficient evidence to move a lane, and what
it gets wrong is not random. The survivors are link text, language-of-parts and images-of-text,
where the answer is largely derivable from the document; the casualties are alt text and
contrast, where it is a judgement the model makes differently on a second pass.

**The free baseline was rewritten after both runs, and it changes no verdict here — measured,
not assumed.** #1760 re-keyed the rule tier on (criterion, root cause) instead of criterion
alone, fixing the `docx:1.3.1` write that both runs recorded as its one defect. Re-running
`rules-only` against the current corpus (free, no network) gives **zero per-category safety
flips across all 60 categories**, so every verdict below stands. What did change is
candidate-level: with that defect gone the rule tier now passes all five gates — the first
candidate of any kind, in any run, to do so. The reports keep the pre-fix baseline because that
is what the paid tiers were measured beside; the Claude candidates are a separate code path and
are unaffected.

**Sonnet's critical violation did not recur.** Run (a) had it write alt text onto a decorative
image on `docx:1.1.1` (1 of 3 repeats); run (b) recorded zero critical violations on all three
tiers. One occurrence in six repeats across two runs. The panel keeps a per-run safety row so
that fact stays visible rather than being averaged into "clean".

## What this does and does not license

- **Do:** pilot the seven enable categories — six on Sonnet 5 (`docx:1.4.5`, `docx:2.4.4`,
  `html:2.4.4`, `html:3.1.2`, `pptx:1.4.5`, `pptx:3.1.2`) and `pdf:1.4.3` on Opus 5, which is
  the cheapest tier that was safe there — with the reviewer's accept/reject recorded against
  each draft (#1659 and #1662 already link drafts to reviewer outcomes). Six have two runs
  behind them; `pptx:1.4.5` has one, because its lane only entered the corpus between the runs.
  All seven are assisted lanes already: enabling means the draft is machine-written, not that
  it is applied.
- **Do not:** treat the five that failed to replicate as rejected. They are unresolved — safe in
  one run, not the other — and a third run is what settles them.
- **Do not:** promote any human lane. None reached enable under two runs.
- **Still true, and unchanged by any run:** every paid tier fails autonomous-action precision
  (42-59% against 90%) and cost (170x over budget after routing). Nothing here is an autonomous
  lane, and nothing here removes human approval.

## Limits

- The executor is simulated; "verified" means the case's predicates passed on the fixture.
- One prompt, zero-shot. Diagnosis scores (42-48%) measure that prompt on these models.
- List price, read 2026-06-24. Rankings do not move; dollars do.
- `docx:3.1.1` and `pptx:1.4.5` are judged on one run each: the corpus changed their case
  count between the two runs, so only the run matching the current corpus is pooled into them.
- Two runs is enough to reject a claim (it rejected five) and thin to establish one. A category
  safe in both runs has six repeats behind it, not a confidence interval.

## Shadow-mode Claude vs. the current remediation lane

Reports (2 independent shadow run(s), same 143-case corpus, same graders):

- `evals/reports/2026-09-07-hosted-ladder-142.json`
- `evals/reports/2026-09-07-hosted-ladder-143-run2.json`

Shadow candidates judged: `anthropic:claude-haiku-4-5`, `anthropic:claude-opus-5`, `anthropic:claude-sonnet-5`. Baseline: `rules-only` (the product's deterministic auto lane, $0).

**Decision rule (declared before the reports were read).** A tier is *safe* in a category when, in that run, it recorded zero critical violations, declined every must-abstain case and verified every automation-eligible case — the ladder's own definition. A category is judged on a tier only when the tier was safe in EVERY run.

- **enable** — a Claude tier safe in all runs, ≥2 cases, rule code not already safe. Enable means ASSISTED (Claude proposes, a human approves) — the cost gate and calibration findings in the hosted-run writeup rule out an autonomous lane.
- **keep-human-only** — adequately sampled and no Claude tier safe in any run; or the category is entirely must-abstain (the evidence is whether Claude declined it).
- **insufficient-evidence** — fewer than 2 cases, or a tier safe in some runs and not others.
- **no-change-rule-code** — rule code safe in every run; a paid tier is dominated.

**Judged on fewer runs than the rest:** `docx:3.1.1` (1 of 2), `pptx:1.4.5` (1 of 2). The corpus changed the number of cases in these categories between runs, so the runs that saw a different case set are not pooled into them — agreement is decided per category, never averaged across two case sets.
