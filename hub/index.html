LLM Traces — Langfuse
Scan · Assess · Remediate — 3 clean traces
Opens the ACP Demo (Google Drive) project. Each run writes three clearly-named traces: Scan (Deep) — a span per document + 🔒 PII; Assess — per-document, per-WCAG-rule ✓/✗ (written when a user runs Assess); and Remediate — a span per fixed file. Filter by the user: tag to see one person's runs.
